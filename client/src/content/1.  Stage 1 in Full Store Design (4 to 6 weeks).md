# 📅 Week 1: Setup and Learning the Admin

## 1.1 Create a free dev store

Dev stores are **free and never expire**. You can place **unlimited test orders** with Shopify’s Bogus Gateway.

**Steps:**

1. Sign up for a free **Shopify Partner** account
2. Go to the **Dev Dashboard** → **Stores** → **Create store**
3. For store type, choose **Dev**
4. Name the store **solenne-demo** (this becomes your [myshopify.com](http://myshopify.com/) address)
5. Leave **Generate test data** unchecked, because you’ll add your own products

**Good to know:** dev stores are **always password-protected**. To show clients, give them the password (set it in **Online Store → Preferences**). You can edit the password page, but visitors won’t see your custom version.

## 1.2 Pick a theme: the Horizon family

Horizon includes 10 free themes: **Horizon, Atelier, Dwell, Fabric, Heritage, Pitch, Ritual, Savor, Tinker and Vessel.** They all use **the same code with different starting settings.**

- **Recommended for SOLENNE:** **Ritual**, which is already suited to beauty and wellness, or plain **Horizon**
- **Use the latest version.** Horizon 4.0+ uses the new **color palette** system.
- **Why Horizon:** it has **nested theme blocks**, it supports **AI-generated blocks**, and it’s what Shopify is investing in

**Steps:** Online Store → Themes → Add theme → search “Ritual” → Add → **Publish**, then **Duplicate** it as a backup.

## 1.3 Learn the admin (the main areas)

| Area | What to learn |
| --- | --- |
| **Products** | Title, description, media, price, compare-at price, SKU, inventory, variants |
| **Collections** | Manual collections vs. **automated** ones (built from rules) |
| **Content → Menus** | Main menu and footer menu, with **nested levels** |
| **Online Store → Pages** | Page templates |
| **Settings → Policies** | Refund, privacy, terms, shipping and contact policies |
| **Settings → Custom data** | Metafield definitions (used in week 2) |
| **Settings → Shipping, Taxes, Markets** | Basic setup so checkout works |
| **Online Store → Preferences** | Page title, meta description, social share image, password |

**✅ Done when:** you can explain what every admin menu item does.

**For every product:** SKU, weight (so shipping can be calculated), inventory, **product category** from Shopify’s standard taxonomy, tags (for example `concern:dryness`, `step:1`), and SEO title and description.

## 2.2 The bundle: use Shopify Bundles (free)

**Shopify Bundles** is Shopify’s own free app for fixed bundles and multipacks.

**Steps:** install **Shopify Bundles** → **Create bundle** → add the Cleanser 150 ml, Serum 30 ml and Cream → set the price → save.

**Lesson for later:** bundles affect inventory, so check that stock goes down for each product in the bundle.

## 2.3 Metafields (setup only, no code)

**Settings → Custom data → Products → Add definition:**

| Metafield | Type | Example |
| --- | --- | --- |
| `custom.skin_type` | List of single-line text | Dry, Normal, Sensitive |
| `custom.key_ingredients` | Multi-line text | Hyaluronic acid, Squalane |
| `custom.how_to_use` | Rich text | “Apply 2–3 drops…” |
| `custom.size_note` | Single-line text | “Lasts ~2 months” |

**Category metafields:** once you set a product’s category, Shopify may suggest ready-made attributes for that category. **Use them when they’re available.** They help filtering and AI shopping assistants.

**Why this matters:** in week 4 you’ll connect these to the product page through **dynamic sources**, with no code. In Stage 3 you’ll use them in Liquid.

- ✅ **Alt text** on every image, for example *“Hydrating Serum 30 ml frosted glass dropper bottle”*

## 2.5 🤖 Product descriptions with Magic and Sidekick

**Magic:** in the product description editor, click **Generate text** and add a few key points.

**Sidekick prompt (paste into the purple glasses chat):**

> *“Write a product description for SOLENNE Hydrating Serum. Audience: women 25–40 who want a calm, simple routine. Tone: calm, honest, warm, no hype words like ‘miracle’ or ‘flawless’. Structure: 1 short opening line, 3 benefit bullets, 1 sentence on texture. Max 90 words. Key ingredients: hyaluronic acid, squalane.”*
> 

**Then edit it into the brand voice yourself:**

- ❌ Remove generic filler (“elevate your routine”, “game-changer”)
- ❌ **Remove any medical claims** (“cures acne”, “clinically proven” without evidence). Cosmetics have legal limits on claims.
- ✅ Keep sentences short, concrete and calm
- ✅ Use the same structure for all 4 products

**✅ Done when:** all products, variants, the bundle, metafields, images and descriptions are complete.

# 📅 Week 3: Brand System in the Theme

**Online Store → Themes → Customize → Theme settings (gear icon)**

## 3.1 Colors: palette first

Horizon 4.0+ uses **color palettes**: one grid of colors that applies across the whole theme, which you can override per section or block. Palettes are the system Shopify is building on going forward.

| Role | Color |
| --- | --- |
| Background | Ivory `#F6F1EA` |
| Alternate background | Sand `#E4D5C3` |
| Text + primary button | Deep olive `#3F4A3C` |
| Secondary | Sage `#8A9A7B` |
| Accent | Terracotta `#C9785D` |

### ⚠️ An accessibility lesson built into this palette

- **Deep olive on ivory ≈ 8.3:1 contrast.** ✅ Great for text and buttons.
- **Terracotta on ivory ≈ 3:1 contrast.** ❌ **This fails WCAG** for normal text, which needs 4.5:1.
- **The rule:** use terracotta **only for decoration** (badges, lines, icons). **Primary buttons should be deep olive with ivory text.**
- **Tool:** always check with WebAIM’s Contrast Checker. **You can point this out to clients**, and it shows you know your craft.

## 3.2 Typography

| Element | Setting |
| --- | --- |
| **Headings** | An elegant serif from Shopify’s font library (for example Cormorant or Playfair) |
| **Body** | A clean sans-serif (for example Inter or DM Sans) |
| **Body size** | **16px or larger** on mobile |
| **Type scale** | Use clear steps, for example 16 → 20 → 28 → 40 → 56px |
| **Line height** | Around 1.5 for body text, 1.1–1.2 for headings |

**Rule:** use **two fonts at most.** Every extra font slows the site down.

## 3.3 Other global settings

- **Buttons:** one clear primary style (olive, filled) and one secondary style (outlined)
- **Corner radius:** pick one value (for example 4px) and **use it everywhere**
- **Spacing:** keep section padding consistent (for example 64px on desktop, 40px on mobile)
- **Logo:** upload the transparent PNG or SVG and set its width in the header
- **Favicon:** use the icon from prompt 2
- **Social media links:** use placeholders for now

## 3.4 Design basics: the 5 rules to learn

1. **Hierarchy:** each section has **one main message**. It should be the biggest and first thing people see.
2. **Spacing:** use a **consistent scale** (8, 16, 24, 32, 48, 64). Generous white space makes a store feel premium.
3. **Alignment:** keep a **consistent grid**, and don’t mix centered and left-aligned text within the same section.
4. **Consistency:** the same button, radius and image style throughout.
5. **Mobile first:** **most ecommerce traffic is mobile**, so design and check on mobile first.

**✅ Done when:** the theme settings work as a brand system, and any page looks like SOLENNE without per-page tweaking.

# 📅 Week 4: Homepage, Product and Collection Pages

## 4.1 Homepage structure

| # | Section | Purpose |
| --- | --- | --- |
| 1 | **Announcement bar** | “Free shipping over $60” |
| 2 | **Header** | Logo, menu, search, account, cart |
| 3 | **Hero** | Headline + 1 button (hero image with no text in it) |
| 4 | **Shop by concern** | Cards for Dryness, Sensitivity, Dullness |
| 5 | **Best sellers** | A product grid showing 4 products |
| 6 | **Ingredient story** | Image + text: “What’s inside, and why” |
| 7 | **Routine bundle** | Feature the Daily Routine Set |
| 8 | **Reviews / trust** | Trust badges (see the note below) |
| 9 | **Newsletter** | “10% off your first routine” |
| 10 | **Footer** | Menus, policies, social links |

**Hero copy example:**

- **Heading:** *“Simple routines. Calm skin.”*
- **Subheading:** *“Four botanical essentials, nothing you don’t need.”*
- **Button:** *“Build your routine”*

**⚠️ Honesty rule:** **don’t invent reviews**, not even on a demo store. Use trust badges instead (Cruelty-free, Recyclable glass, 30-day returns), or label reviews clearly as **“Sample review — demo store.”**

## 4.2 Product page (the most important page)

**In order, from top to bottom:**

1. **Media gallery:** packshot → texture → lifestyle
2. **Title + price** (and compare-at price for the bundle)
3. **Short benefit line**
4. **Variant picker** for size
5. **Add to cart** as the clear primary button
6. **Trust line:** “Free shipping over $60 · 30-day returns”
7. **Collapsible tabs:** Key ingredients · How to use · Skin type
8. **Complementary products:** “Complete your routine”

**🔗 Dynamic sources (no code):** click a text block’s setting → the **Connect dynamic source** icon → choose a metafield (for example `custom.how_to_use`). **One template then works for all 4 products.** This is the most important skill in Stage 1.

## 4.3 Collection pages

- **Collection banner:** image + short description
- **Filters:** set these up in week 5 with Search & Discovery
- **Grid:** 2 columns on mobile, 3–4 on desktop
- **Product cards:** show a second image on hover and a clear price

## 4.4 The 3 collections (make at least one automated)

| Collection | Type | Condition |
| --- | --- | --- |
| **Cleansers** | Automated | Product type = Cleanser |
| **Serums & Oils** | Automated | Product type = Serum **or** Face Oil |
| **Moisturizers** | Automated | Product type = Moisturizer |

**Why automated:** new products are added to the right collection automatically. **Clients love this.**

**✅ Done when:** the homepage, product and collection pages look professional **on mobile and desktop.**

## 5.4 Search & Discovery app (free)

Install **Shopify Search & Discovery**:

| Feature | What to set up for SOLENNE |
| --- | --- |
| **Filters** | Availability, Price, Product type, **Skin type (metafield)**, Size |
| **Synonyms** | See below |
| **Product boosts** | Pin the Serum at the top of searches for “hydration” |
| **Recommendations** | Cleanser → Serum → Cream as “Complete your routine” |

**Synonym groups** (each synonym can be 1–5 words):

- moisturizer, moisturiser, cream, face cream
- serum, essence, booster
- cleanser, face wash, facial wash
- face oil, facial oil

## 5.5 🤖 The Magic block generator experiment

**Purpose:** find out **what merchants can build without you.** That tells you what to charge for.

**Steps:** Customize → click a section that accepts theme blocks → **Add block** → **Generate** → write the prompt → **Keep** or **Discard**.

**Test prompt 1 (simple):**

> *“A trust badges block with 4 items in a row: icon, short title, one-line text. Items: Cruelty-free, Recyclable glass, 30-day returns, Free shipping over $60. Stack 2x2 on mobile. Include settings to edit each title, text and icon color.”*
> 

**Test prompt 2 (harder):**

> *“A routine steps block showing 3 numbered steps side by side (Cleanse, Treat, Moisturize), each with a product image, step number, product name, short text and an ‘Add to cart’ button that adds the product without leaving the page.”*
> 

**Write down what happened in a table:**

| Test | Worked? | Problems found |
| --- | --- | --- |
| Trust badges | ? | Code quality, mobile, settings |
| Routine + AJAX add-to-cart | ? | Did the cart work? Did it pass accessibility checks? |

**What you should find:**

- ✅ Simple visual blocks usually work well
- ❌ Complex logic (AJAX cart, data from other products) often breaks or misbehaves
- Generated code is saved to the **`/blocks` folder**. Shopify itself says it **may not meet accessibility or performance best practices.**
- Users report that **after you save a block, you can’t edit it with AI prompts again**, only in code

**👉 Conclusion:** simple blocks are now free for merchants. **Custom logic, clean architecture and quality are what you sell.**

## 5.6 🤖 Sidekick experiments (write down the results)

Try these and **note what Sidekick did and didn’t do:**

1. *“Create a discount code WELCOME10 for 10% off first orders.”* → ✅ it usually handles this
2. *“Find products with no SEO description.”* → ✅ useful
3. *“Change my homepage hero image to the serum photo.”* → ❌ **Sidekick generally can’t edit the storefront theme**
4. *“Show me my store’s web performance.”* → ✅ Sidekick can now query web performance data

**✅ Done when:** all pages, navigation, filters and synonyms are working, and your AI results table is filled in.

# 📅 Week 6: QA, Numbers, Portfolio and Selling

## 6.1 QA checklist

**Functionality:**

- ☐ Every link works (no 404s)
- ☐ **A test order** through the Bogus Gateway works from start to finish
- ☐ The bundle adds to cart properly and inventory goes down correctly
- ☐ Filters and search work, including synonyms
- ☐ The newsletter and contact forms send
- ☐ Variants change the price and image correctly

**Design:**

- ☐ Checked on **real phones**, not just the editor preview
- ☐ Nothing overflows sideways on mobile
- ☐ Consistent spacing, fonts and buttons
- ☐ All images are sharp and consistent

**Accessibility:**

- ☐ Contrast passes (no terracotta text)
- ☐ Alt text on all images
- ☐ You can use the whole store with the **keyboard** (Tab through it)
- ☐ Headings are in order (one H1 per page)

**SEO basics:**

- ☐ Page titles and meta descriptions on the homepage, products and collections
- ☐ Clean URLs, for example `/products/hydrating-serum`
- ☐ A social share image is set

## 6.2 Baseline numbers (you’ll need them in Stage 4)

- Run **PageSpeed Insights** on the homepage, a product page and a collection page (for mobile and desktop)
- **Save screenshots.** These are your “before” numbers.
- **Note:** password-protected stores can be hard to test with external tools. If you can’t, use Lighthouse in Chrome DevTools while logged in.

## 6.3 Portfolio deliverables

1. **Screenshots** of the homepage, product and collection pages (desktop and mobile)
2. **A 2–3 minute Loom walkthrough** of the store
3. **A short case study:**
    - **Brief:** “A calm, premium skincare store”
    - **Decisions:** palette, fonts, page structure, and **why** (for example the contrast fix)
    - **Built:** dynamic product pages, automated collections, filters, bundle
    - **AI workflow:** what AI did vs. what you did
4. **The store link + password** to share with prospects

| Package | Price | Includes |

| **Starter** | $500–$800 | Horizon setup, brand settings, homepage, up to 10 products, basic pages, policies |

1. Who is your customer, and what do they worry about before buying?

**How to position yourself against AI:**
