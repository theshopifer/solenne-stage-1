# 📅 Week 3: Brand System in the Theme (full step-by-step guide)

# **Week goal:**

turn SOLENNE’s brand into global theme settings (palette, fonts, type sizes, buttons, badges, inputs, cart, logo and favicon), so any page looks like SOLENNE without adjusting each page separately.

**Time needed:** about 1–1.5 hours a day for 7 days.

I checked this against Horizon’s current settings file (**version 4.2.0**) and Shopify’s Help Center. **Five corrections to what I told you earlier:**

- **Horizon has 4 font slots, not 2:** Body, Subheading, Heading and Accent. You still use **only 2 font families**; you just assign them to the 4 slots.
- **Line height is a choice of Tight, Normal or Loose**, not a number you type in.
- **Paragraph text sizes stop at 18px.** Headings go from 10px up to 184px, in fixed steps.
- **Section padding isn’t a global setting.** Each section has its own padding sliders. This week you set the spacing *rule*, and you apply it in Week 4.
- **I checked more color pairs, and some fail.** Sage on ivory is only about 2.7:1, so **sage can’t be used for text either.** I’ve added two darker “text-safe” colors to fix this.

# 🟢 Day 2: Color Palette and Contrast Testing

## 2.1 How palettes work

- A palette is **one set of named brand colors for the whole theme**
- **Change a palette color once and every place that uses it updates**
- Sections and blocks can **override** a color for local changes
- A palette can hold **2–20 colors**
- The two built-in colors are **Background** and **Foreground**. Horizon uses them as defaults for buttons, drawers, inputs and badges.

## 2.2 SOLENNE’s final palette (8 colors)

| # | Palette name | Hex | Role | Can it be text on ivory? |
| --- | --- | --- | --- | --- |
| 1 | **Background** | `#F6F1EA` | Ivory: page background | — |
| 2 | **Foreground** | `#3F4A3C` | Deep olive: text, primary button | ✅ **≈ 8.3:1** |
| 3 | **Sand** | `#E4D5C3` | Alternate section background | — |
| 4 | **Sage** | `#8A9A7B` | **Decoration only** (lines, icon backgrounds) | ❌ ≈ 2.7:1 |
| 5 | **Sage Deep** 🆕 | `#5E6B52` | Secondary text, links, captions | ✅ **≈ 5.0:1** |
| 6 | **Terracotta** | `#C9785D` | **Decoration only** (dividers, small details) | ❌ ≈ 2.9:1 |
| 7 | **Terracotta Deep** 🆕 | `#A0533A` | **Sale badges**, important highlights | ✅ **≈ 4.9:1** |
| 8 | **White** | `#FFFFFF` | Input fields, cards | — |

## 2.3 Set up the palette

1. **Theme settings → Colors**
2. Click **Background** → enter `#F6F1EA`
3. Click **Foreground** → enter `#3F4A3C`
4. **Add color** → name it **Sand** → `#E4D5C3`
5. Repeat for **Sage, Sage Deep, Terracotta, Terracotta Deep and White**
6. **Save**

**Tip:** name colors by **role or color name** (Sand, Sage Deep), not “Color 3.” Names show up in the color picker everywhere.

## 2.4 Contrast testing: the full table

**WCAG AA rules:** normal text needs **4.5:1**; large text (24px+, or 18.66px+ bold) and interface parts like button borders and icons need **3:1**.

| Text / foreground | Background | Ratio | Normal text | Large text / UI |
| --- | --- | --- | --- | --- |
| Deep olive | Ivory | **≈ 8.3** | ✅ | ✅ |
| Ivory | Deep olive (primary button) | **≈ 8.3** | ✅ | ✅ |
| Deep olive | Sand | **≈ 6.5** | ✅ | ✅ |
| Sage Deep | Ivory | **≈ 5.0** | ✅ | ✅ |
| Ivory | Terracotta Deep (sale badge) | **≈ 4.9** | ✅ | ✅ |
| Deep olive | Sage | **≈ 3.1** | ❌ | ⚠️ Large only |
| Terracotta | Ivory | **≈ 2.9** | ❌ | ❌ |
| Sage | Ivory | **≈ 2.7** | ❌ | ❌ |

**The ratios are my calculations. Check every pair yourself** at [**webaim.org/resources/contrastchecker**](http://webaim.org/resources/contrastchecker) and **paste screenshots into your style guide.**

## 2.5 Color rules (copy these into the style guide)

- ✅ **Text:** only Foreground (deep olive) or Sage Deep
- ✅ **Primary button:** deep olive background with ivory text
- ✅ **Sale badges:** Terracotta Deep with ivory text
- ✅ **Alternate sections:** Sand background with deep olive text
- ❌ **Never use Sage or Terracotta for text or button fills.** They’re decoration only.
- ❌ Don’t put text directly on busy parts of photos (that’s why the heroes have empty space)

## 2.6 Page text color

**Theme settings → Typography → Colors → Page text color:** leave it linked to **Foreground**.

**Page layout → Page background color:** leave it linked to **Background**.

**Why keep them linked:** if the client ever changes their brand colors, **one change in the palette updates everything.**

# 🟢 Day 3: Fonts and Type Sizes

## 3.1 Two families across 4 slots

| Horizon slot | Font | Style | Used for |
| --- | --- | --- | --- |
| **Heading** | **Cormorant Garamond** | Regular or Medium | H1–H3, hero headings |
| **Accent** | **Cormorant Garamond** | Italic | Occasional emphasis, quotes |
| **Body** | **DM Sans** | Regular | Paragraphs, buttons, prices |
| **Subheading** | **DM Sans** | Medium | H4–H6, labels, the eyebrow text above headings |

**Fonts not in the library?** Shopify’s font library includes system fonts and a selection of Google Fonts, so check the picker. **Serif alternatives:** Playfair Display, EB Garamond or Lora. **Sans-serif alternatives:** Inter, Karla or Work Sans.

**⚠️ Performance note:** **every weight and style is a separate file.** Two families with 4 styles is the practical maximum. **Don’t add bold italic or extra weights.**

## 3.2 Select the fonts

1. **Theme settings → Typography → Fonts**
2. **Body** → Change → search “DM Sans” → choose **Regular (400)**
3. **Subheading** → DM Sans → **Medium (500)**
4. **Heading** → Cormorant Garamond → **Medium (500)** (Regular can look too thin on screen)
5. **Accent** → Cormorant Garamond → **Italic**
6. **Save**

## 3.3 Type sizes (choose from Horizon’s options)

| Preset | Font | Size | Line height | Letter spacing | Case |
| --- | --- | --- | --- | --- | --- |
| **Paragraph** | Body | **16px** | Normal | — | — |
| **H1** | Heading | **56px** | Tight | Tight | Default |
| **H2** | Heading | **40px** | Tight | Normal | Default |
| **H3** | Heading | **32px** | Normal | Normal | Default |
| **H4** | Subheading | **24px** | Normal | Normal | Default |
| **H5** | Subheading | **18px** | Normal | Normal | Default |
| **H6** | Subheading | **14px** | Normal | **Loose** | **Uppercase** |

**Why these sizes:**

- **16px body** is the minimum for comfortable reading on mobile (Horizon’s default is 14px, which is too small)
- **Each step is clearly different** from the one below: 14 → 18 → 24 → 32 → 40 → 56
- **Large serif headings look better slightly tight**; small text needs normal or loose spacing
- **H6 in uppercase with loose spacing** makes a calm “eyebrow” label, for example *KEY INGREDIENTS*

## 3.4 Set it up

**Theme settings → Typography → Text presets** → for Paragraph and H1–H6, set the font, size, line height, letter spacing and case from the table → **Save**

## 3.5 Check on mobile

- Switch the editor to **mobile preview**
- Horizon **scales large headings down on mobile automatically**, but check that:
    - ☐ The H1 in the hero stays within about **3 lines**
    - ☐ Body text is readable without zooming
    - ☐ Long product names don’t break awkwardly
- **Too big on mobile?** Lower H1 to **48px** instead of adding custom CSS.

## 3.6 Text rules (for the style guide)

- **One H1 per page** (the hero heading or the product title)
- **Headings are short:** at most about 8 words
- **Paragraphs are short:** 2–4 lines on mobile
- **Line length on desktop:** about 60–75 characters, which a narrow or normal page width gives you
- **Use italic Accent sparingly**, for example one italic word in a heading

- ☐ 4 slots filled from 2 families
- ☐ No extra weights added
- ☐ Paragraph set to 16px
- ☐ H1–H6 set from the table
- ☐ Checked on mobile
- ☐ Text rules added to the style guide

# 🟢 Day 4: Buttons, Badges, Inputs and Icons

## 4.1 Choose one corner radius for everything

**SOLENNE’s choice: 4px**, which reads as soft, calm and premium.

Horizon’s defaults are **pill-shaped** (100px for buttons, 40px for badges and pills, 8px for inputs). **Mixed radii look unplanned**, so set them all to match.

## 4.2 Buttons

**Theme settings → Buttons:**

| Setting | Primary | Secondary |
| --- | --- | --- |
| **Background** | Foreground (deep olive) | Background (ivory) |
| **Text** | Background (ivory) | Foreground (deep olive) |
| **Border** | Foreground | Foreground |
| **Border width** | 0px | **1px** |
| **Corner radius** | **4px** | **4px** |
| **Font** | Body | Body |
| **Text case** | Default | Default |

**Pills** (filter chips, variant pills) → corner radius **4px**

**Button rules:**

- **One primary button per section.** It’s the main action.
- **The secondary button** is for less important actions (*“Learn more”*)
- **Button text is a verb:** *“Add to cart,” “Build your routine,” “Shop serums”*
- **Minimum tap size about 44px** on mobile (Horizon usually handles this, but check)

## 4.3 Badges

**Theme settings → Badges:**

| Setting | Value |
| --- | --- |
| **Position** | Top-left |
| **Corner radius** | **4px** |
| **Sale background** | **Terracotta Deep** `#A0533A` |
| **Sale text** | Background (ivory) |
| **Sold out background** | Background (ivory) |
| **Sold out text** | Foreground (deep olive) |
| **Font** | Subheading |
| **Text case** | **Uppercase** |

**Check:** the bundle has a compare-at price, so its **sale badge should appear**. Look at it on the homepage or a collection page.

## 4.4 Input fields

**Theme settings → Input fields:**

| Setting | Value |
| --- | --- |
| **Background** | **White** `#FFFFFF` (fields stand out slightly from the ivory page) |
| **Text** | Foreground |
| **Border** | Foreground (or Sage Deep for a softer look) |
| **Border width** | 1px |
| **Corner radius** | **4px** |
| **Type preset** | Paragraph |

**Accessibility:** input borders need **3:1 contrast** against the page. Deep olive and Sage Deep both pass. **Plain Sage doesn’t.**

## 4.5 Icons

**Theme settings → Icons → Stroke:** **Thin** or **Default**

- **Thin** looks elegant and matches the serif headings
- **Check** that thin icons are still clear on mobile. If they look too faint, use **Default**.

# 🟢 Day 6: Spacing Rules and Design Basics Practice

## 6.1 SOLENNE’s spacing standard

**Scale:** 8 · 16 · 24 · 32 · 48 · 64 · 96

| Where | Desktop | Mobile |
| --- | --- | --- |
| **Section padding, top and bottom** | **64px** | **40px** |
| **Hero section** | 96px (or full screen) | 48px |
| **Gap between heading and text** | 16px | 16px |
| **Gap between text and button** | 24–32px | 24px |
| **Gap between grid items** | 24px | 16px |
| **Page edge margin** | Set by the theme | Set by the theme |

**Important:** in Horizon, **each section has its own padding sliders** (in the section’s settings). There’s no global setting. **You’ll apply this standard to every section in Week 4.**

**Tip:** when two sections next to each other **have the same background**, the space between them doubles. **Reduce one section’s padding, or alternate ivory and sand backgrounds.**

## 6.2 The 5 design rules, with practice

**Try each rule on the current homepage (Ritual’s demo content is fine) and take before and after screenshots.**

**Rule 1: Hierarchy.** *Each section has one main message.*

- **Test:** squint at the screen (or blur a screenshot). **Can you still tell what matters most?**
- **Practice:** in the hero, make the heading clearly the largest, keep the subheading shorter, and use one button.

**Rule 2: Spacing.** *Use a consistent scale, and let generous space signal premium.*

- **Test:** do all sections have similar gaps? **Uneven gaps are the quickest sign a store is amateur.**
- **Practice:** set 2–3 sections to 64 / 40px padding.

**Rule 3: Alignment.** *Consistent grid, and don’t mix alignments within a section.*

- **Test:** draw imaginary vertical lines. **Do headings, text and buttons line up?**
- **Practice:** choose **left-aligned** for content sections and **centered** only for short sections like the newsletter.

**Rule 4: Consistency.** *The same button, radius and image style everywhere.*

- **Test:** find every button, badge and input field. **Do they all have the 4px radius?**
- **Practice:** look for anything the theme settings didn’t change and write it down.

**Rule 5: Mobile first.** *Most ecommerce traffic is mobile.*

- **Test:** **check every change in mobile preview first**, then desktop.
- **Practice:** look at the hero, product grid and footer on mobile.

# 🟢 Day 7: Mobile-First Testing, QA and Style Guide

## 7.1 Test on real devices

**Open the store on your phone** (with the password). **The editor preview is not enough.**

**Mobile:**

- ☐ Body text is readable without zooming
- ☐ H1 fits in about 3 lines
- ☐ Buttons are easy to tap
- ☐ The logo is sharp and the right size
- ☐ Nothing overflows sideways
- ☐ The cart drawer opens after adding a product and **is easy to close**
- ☐ The favicon shows in the browser tab

**Desktop:**

- ☐ Line length is comfortable
- ☐ The product grid looks balanced at the chosen page width
- ☐ Hover effects are subtle

## 7.2 Consistency audit

**Look at every page type:** Home · Collection · Product · Cart drawer · Search · Pages · 404 (visit `/abc`) · Password page

| Check | Home | Collection | Product | Cart | Search | Page | 404 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| Fonts correct | ☐ | ☐ | ☐ | ☐ | ☐ | ☐ | ☐ |
| Colors from the palette | ☐ | ☐ | ☐ | ☐ | ☐ | ☐ | ☐ |
| 4px radius | ☐ | ☐ | ☐ | ☐ | ☐ | ☐ | ☐ |
| Buttons consistent | ☐ | ☐ | ☐ | ☐ | ☐ | ☐ | ☐ |
| No text contrast failures | ☐ | ☐ | ☐ | ☐ | ☐ | ☐ | ☐ |

**Found something that doesn’t match?** First look for a **global setting** that controls it. **Only change a single section if no global setting exists**, and write it down.

## 7.3 Keyboard test (basic accessibility)

- ☐ Press **Tab** through the homepage. **Can you always see where the focus is?**
- ☐ Can you open the menu, search and the cart with the keyboard?
- ☐ Does **Esc** close the cart drawer?

**Write down any problems.** Some may need code fixes in Stage 2.

## 7.4 The “brand switch” test (the real test of Week 3)

1. **Duplicate the theme** as `Test — palette switch`
2. In the duplicate, **change Foreground** from olive to navy `#1F2A44`
3. **Does the whole store change at once?** Text, buttons, badges, drawers?
4. If it does, **your brand system works.** 🎉
5. **Delete the test theme**

**This proves the “Done when” goal, and it’s a great point for your case study:** *“The client can change brand colors in one place.”*

## 7.5 Finish the style guide

**The final style guide should include:**

1. **Colors:** the 8 swatches, their roles, **contrast screenshots**, and the rules
2. **Typography:** the 2 families, the 4 slots, and the size table for H1–H6 and paragraph
3. **Interface:** buttons, badges, inputs, the 4px radius, icon stroke
4. **Spacing:** the scale and the section padding table
5. **Layout:** page width and the reason for it
6. **Images:** the Brand Anchor summary
7. **Voice:** the rules from Week 2

**Export it as a PDF** called `SOLENNE-Style-Guide-v1.pdf`.
