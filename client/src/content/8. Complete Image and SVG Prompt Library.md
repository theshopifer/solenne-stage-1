# SOLENNE: Complete Image and SVG Prompt Library

# Guide:

These prompts are written for gpt-image-2. The SVG section is written for a text AI (ChatGPT free or Gemini inside Antigravity), because image models output pixels, not vector code. Filenames match the ones used in Weeks 2 to 6, so each file drops straight into the store.

---

## 0. How to use this library

**Workflow (follow this order):**

1. Paste the **Brand Anchor** (section 1) at the top of every prompt, wherever you see `[BRAND ANCHOR]`.
2. Generate the **master packshot** first (B1, Hydrating Serum 30 ml). Keep generating until it’s right, because every other product image uses it as a reference.
3. For every later product image, **upload the approved master as a reference image** and say: “Match the lighting, background, camera angle, glass finish, and label design of the reference image exactly.”
4. Use **quality: high** for packshots, heroes, and the logo. Medium is fine for drafts.
5. Check all label text letter by letter. If it’s wrong, use the fix prompts in section 12. Don’t regenerate the whole image.
6. Post-process: crop to final size, convert to WebP in Squoosh (quality 80–85), rename, and add alt text.

**Size rules:** both sides must be multiples of 16. If a size gets rejected, generate at 1536×1024 (landscape) or 1024×1536 (portrait), then crop or upscale.

**Honesty rules:** don’t make images of fake customers giving reviews. Don’t add fake certification seals like Leaping Bunny, dermatologist-approved, or organic logos. Don’t use clinical or medical imagery. If you use a human face for a demo store, label it “illustrative” in the case study.

## 1. Brand Anchor (paste into every prompt)

```
[BRAND ANCHOR — SOLENNE]
Brand: SOLENNE, a small botanical skincare brand. Calm, honest, minimal, premium but not luxury-flashy. Mood: quiet morning light, natural materials, slow ritual.

Color palette (use these exact tones):
- Ivory #F6F1EA (main background)
- Sand #E4D5C3 (secondary surfaces)
- Deep olive #3F4A3C (caps, lids, text on labels)
- Sage #8A9A7B (botanical accents, leaves)
- Terracotta #C9785D (small warm accents only, max 5% of the image)

Packaging system (identical across all products):
- Glass: soft frosted translucent glass, slightly warm white tint, smooth matte finish, subtle realistic edge reflections.
- Caps/lids/pumps: matte deep olive (#3F4A3C), no shine, no metal parts visible.
- Label: rectangular ivory uncoated paper label, centered, thin margins. Top line: "SOLENNE" in elegant high-contrast serif capitals, wide letter-spacing. Middle: product name in small clean sans-serif capitals. Bottom: size in small sans-serif. Deep olive ink only. No other text, no icons, no barcodes on the front.

Photography style: professional studio product photography, soft diffused natural window light from the left, gentle soft shadow falling to the right, shallow but not extreme depth of field, true-to-life colors, low contrast, slightly warm white balance, no harsh highlights, no HDR look.

Props (only when asked): raw travertine stone, unbleached linen, dried oat stems, fresh sage leaves, chamomile flowers, rosehip, ceramic dish in sand color, water ripples.

Always avoid: extra text, watermarks, other brand logos, fake certification badges, neon or saturated colors, glossy plastic, gold/chrome, clutter, clinical/lab/medical settings, distorted bottles, warped labels, extra fingers, cartoon style, CGI plastic look.
```

> **Important:** use the AI image only to pick a direction. For the real logo, type “SOLENNE” in **Cormorant Garamond Medium** in Inkscape (free), set letter-spacing, convert it with Object → Object to Path, and export as SVG and as a 2× PNG. You get a clean, scalable, correctly spelled logo that is truly yours. AI-generated wordmarks are raster images and often have slightly uneven letters.

```
You are a senior icon designer. Write clean, production-ready inline SVG code for a Shopify skincare store icon set called SOLENNE.

- viewBox="0 0 24 24", width and height="24"
- Outline style only: fill="none", stroke="currentColor", stroke-width="1.5", stroke-linecap="round", stroke-linejoin="round"

- 2px safe padding inside the 24x24 box, optically centered
- Consistent visual weight across the whole set (same corner style, similar detail level)
- Add role="img" and a <title> element for accessibility
- Calm, minimal, botanical feeling; slightly soft, rounded shapes
- Output each icon as a separate code block with the filename as a heading
- After the code, list the path count for each icon (target under 6 paths)

Icons to create:
[PASTE THE LIST BELOW]
```
